# Generative AI and prompt engineering to support environmental analytics


This repository contains the full experimental materials for a study evaluating how six
different prompt engineering strategies — Direct, Role, Few-shot, Chain-of-Thought,
Verification, and Retrieval-Augmented Generation (RAG) — affect the quality, structural
fidelity, and reliability of Python code generated by a large language model (LLM) for the
Air2Water lake surface temperature model (Piccolroaz et al., 2013).

The study evaluates generated code along four dimensions: **code quality and executability**,
**mathematical/structural fidelity to the reference model**, **Code Implementation and Execution**, and **consistency between
the model's natural-language explanations and its actual code**.

## Repository Structure
