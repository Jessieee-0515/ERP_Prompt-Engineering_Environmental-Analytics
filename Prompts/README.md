This folder contains all prompts used in this study. 
The same prompt files are also stored in the `generated_code` directory. By executing these scripts using the OpenAI API, the corresponding LLM-generated outputs can be reproduced. Before running the scripts:

1. pip install openai
2. Set your API key as an environment variable (see chat instructions),
   OR paste it directly into OPENAI_API_KEY below (less secure, fine
   for a personal one-off script).
3. Check MODEL matches a real, currently available dated snapshot from
   https://platform.openai.com/docs/models
