To implement the Air2Water model as described in the reference material, we will follow these steps:

1. **Define the Governing ODE**: We'll use the provided differential equation to model the change in water temperature over time.

2. **Implement Model Parameters**: We'll define the parameters \( p1 \) to \( p8 \) and their respective roles in the model.

3. **Numerically Solve the ODE**: We'll use a numerical solver to integrate the ODE over time.

4. **Calibrate the Model Parameters**: We'll use an optimization method to fit the model to the observed water temperature data.

5. **Report Goodness-of-Fit**: We'll calculate a metric such as the Nash-Sutcliffe efficiency to evaluate the model's performance.

6. **Visualization**: We'll plot the simulated vs observed water temperatures.

Here's the complete Python implementation:

```python
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import differential_evolution
import matplotlib.pyplot as plt

# Define the Air2Water model ODE
def air2water_ode(t, Tw, Ta, params):
    p1, p2, p3, p4, p5, p6, p7, p8 = params
    Tr = 4.0  # Critical temperature for stratification
    tyr = 365.0  # Length of a year in days

    # Calculate normalized mixed layer thickness δ
    if Tw >= Tr:
        delta = np.exp((Tr - Tw) / p6)
    else:
        delta = np.exp((Tw - Tr) / p7) + np.exp(-Tw / p8)

    # Calculate the rate of change of water temperature
    dTw_dt = (1 / delta) * (
        p1 * np.cos(2 * np.pi * (t / tyr - p2)) +
        p3 +
        p4 * (Ta - Tw) +
        p5 * Tw
    )
    return dTw_dt

# Objective function for optimization
def objective_function(params, Ta_obs, Tw_obs):
    # Solve the ODE using the current parameter set
    sol = solve_ivp(
        fun=lambda t, Tw: air2water_ode(t, Tw, Ta_obs[int(t)], params),
        t_span=(0, len(Ta_obs) - 1),
        y0=[Tw_obs[0]],
        t_eval=np.arange(len(Ta_obs))
    )
    Tw_sim = sol.y[0]
    
    # Calculate Nash-Sutcliffe efficiency
    numerator = np.sum((Tw_obs - Tw_sim) ** 2)
    denominator = np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)
    nse = 1 - (numerator / denominator)
    
    return -nse  # Minimize negative NSE

# Define parameter bounds
bounds = [
    (0.00, 0.33),  # p1
    (0.00, 1.00),  # p2
    (-0.12, 0.28), # p3
    (0.00, 0.01),  # p4
    (-0.02, 0.00), # p5
    (0, 15),       # p6
    (0, 15),       # p7
    (0, 0.5)       # p8
]

# Calibrate the model using differential evolution
result = differential_evolution(
    objective_function,
    bounds,
    args=(Ta_obs, Tw_obs),
    strategy='best1bin',
    maxiter=1000,
    popsize=15,
    tol=0.01,
    mutation=(0.5, 1),
    recombination=0.7
)

# Extract the best parameters
best_params = result.x

# Solve the ODE with the best parameters
sol = solve_ivp(
    fun=lambda t, Tw: air2water_ode(t, Tw, Ta_obs[int(t)], best_params),
    t_span=(0, len(Ta_obs) - 1),
    y0=[Tw_obs[0]],
    t_eval=np.arange(len(Ta_obs))
)
Tw_sim = sol.y[0]

# Calculate Nash-Sutcliffe efficiency for the best fit
numerator = np.sum((Tw_obs - Tw_sim) ** 2)
denominator = np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)
nse = 1 - np.sum((Tw_obs - Tw_sim) ** 2) / np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)

# Plot the results
plt.figure(figsize=(10, 6))
plt.plot(Tw_obs, label='Observed Water Temperature', color='blue')
plt.plot(Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
plt.xlabel('Time (days)')
plt.ylabel('Water Temperature (°C)')
plt.title(f'Simulated vs Observed Water Temperature\nNash-Sutcliffe Efficiency: {nse:.2f}')
plt.legend()
plt.show()
```

### Explanation of the Implementation

1. **ODE Definition**: The `air2water_ode` function defines the differential equation based on the provided model structure. It calculates the rate of change of water temperature using the parameters and the current air and water temperatures.

2. **Parameter Calibration**: We use the `differential_evolution` function from `scipy.optimize` to calibrate the model parameters. This method is chosen for its robustness in handling complex, non-linear optimization problems and its ability to work with bounded parameter spaces.

3. **Goodness-of-Fit**: The Nash-Sutcliffe efficiency (NSE) is used as the goodness-of-fit metric. It is a common measure for hydrological models, indicating how well the simulated data matches the observed data.

4. **Visualization**: The final plot compares the observed and simulated water temperatures, providing a visual assessment of the model's performance.

This implementation provides a comprehensive approach to modeling lake surface water temperature using the Air2Water model, with a focus on parameter calibration and model validation.
