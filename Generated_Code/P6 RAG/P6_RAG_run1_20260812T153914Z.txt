To implement the Air2Water model as described in the reference material, we will follow these steps:

1. **Define the Governing ODE**: We'll use the provided differential equation to model the change in water temperature over time.

2. **Implement Model Parameters**: We'll define the parameters \( p1 \) to \( p8 \) and their respective roles in the model.

3. **Numerically Solve the ODE**: We'll use a numerical solver to integrate the ODE over time.

4. **Calibrate the Model Parameters**: We'll use an optimization method to fit the model to the observed water temperature data.

5. **Report Goodness-of-Fit**: We'll calculate a metric such as the Nash-Sutcliffe efficiency to evaluate the model's performance.

6. **Visualization**: We'll plot the simulated vs observed water temperatures.

Here's the complete Python implementation:

```python
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import differential_evolution
import matplotlib.pyplot as plt

# Define the Air2Water model ODE
def air2water_ode(t, Tw, Ta, params):
    p1, p2, p3, p4, p5, p6, p7, p8 = params
    Ta_t = np.interp(t, np.arange(len(Ta)), Ta)  # Interpolate Ta for current time
    Tr = 4.0  # Critical temperature for stratification
    tyr = 365.0  # Length of a year in days

    # Calculate δ based on stratification
    if Tw >= Tr:
        delta = np.exp((Tr - Tw) / p6)
    else:
        delta = np.exp((Tw - Tr) / p7) + np.exp(-Tw / p8)

    # ODE for dTw/dt
    dTw_dt = (1 / delta) * (p1 * np.cos(2 * np.pi * (t / tyr - p2)) + p3 + p4 * (Ta_t - Tw) + p5 * Tw)
    return dTw_dt

# Objective function for optimization
def objective(params, Ta, Tw_obs):
    # Solve the ODE
    sol = solve_ivp(air2water_ode, [0, len(Tw_obs) - 1], [Tw_obs[0]], args=(Ta, params), t_eval=np.arange(len(Tw_obs)))
    Tw_sim = sol.y[0]

    # Calculate Nash-Sutcliffe efficiency
    nse = 1 - np.sum((Tw_obs - Tw_sim) ** 2) / np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)
    return -nse  # Minimize negative NSE

# Parameter bounds based on the reference material
bounds = [(0.00, 0.33), (0.00, 1.00), (-0.12, 0.28), (0.00, 0.01), (-0.02, 0.00), (0, 15), (0, 15), (0, 0.5)]

# Calibrate the model parameters
result = differential_evolution(objective, bounds, args=(Ta_obs, Tw_obs), strategy='best1bin', maxiter=1000, popsize=15)
best_params = result.x

# Solve the ODE with the best parameters
sol = solve_ivp(air2water_ode, [0, len(Tw_obs) - 1], [Tw_obs[0]], args=(Ta_obs, best_params), t_eval=np.arange(len(Tw_obs)))
Tw_sim = sol.y[0]

# Calculate goodness-of-fit metric
nse = 1 - np.sum((Tw_obs - Tw_sim) ** 2) / np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)
print(f'Nash-Sutcliffe Efficiency: {nse:.3f}')

# Visualization
plt.figure(figsize=(10, 6))
plt.plot(Tw_obs, label='Observed Water Temperature', color='blue')
plt.plot(Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
plt.xlabel('Time (days)')
plt.ylabel('Water Temperature (°C)')
plt.title('Simulated vs Observed Water Temperature')
plt.legend()
plt.show()
```

### Explanation of the Implementation

1. **ODE Definition**: The `air2water_ode` function defines the differential equation based on the provided model structure. It calculates the rate of change of water temperature using the parameters and interpolated air temperature.

2. **Parameter Calibration**: We use the `differential_evolution` function from `scipy.optimize` to calibrate the model parameters. This method is chosen for its robustness in handling complex, non-linear optimization problems and its ability to work with bounded parameters.

3. **Goodness-of-Fit**: The Nash-Sutcliffe efficiency (NSE) is used as the goodness-of-fit metric, which is a standard measure for hydrological models.

4. **Visualization**: A plot is generated to compare the simulated water temperatures against the observed data, providing a visual assessment of the model's performance.
