To implement the Air2Water-style lake surface temperature model, we'll follow these steps:

1. **Define the Governing ODE**: We'll create a simple ODE that models the change in water temperature based on air temperature and other parameters.
2. **Implement Model Parameters**: We'll define parameters that influence the model, such as response time and equilibrium temperature.
3. **Numerically Solve the ODE**: We'll use a numerical solver to simulate the water temperature over time.
4. **Calibrate Model Parameters**: We'll use an optimization method to fit the model to the observed water temperature data.
5. **Report Goodness-of-Fit**: We'll calculate a metric like the Root Mean Square Error (RMSE) to evaluate the model's performance.
6. **Visualization**: We'll plot the simulated vs observed water temperatures.

Here's the complete Python implementation:

```python
import numpy as np
from scipy.integrate import odeint
from scipy.optimize import minimize
import matplotlib.pyplot as plt

# Define the governing ODE
def air2water_ode(Tw, t, Ta, params):
    K, Teq_offset = params
    Teq = Ta + Teq_offset  # Simple linear relationship for equilibrium temperature
    dTw_dt = K * (Teq - Tw)
    return dTw_dt

# Numerical solver for the ODE
def solve_ode(Ta, Tw0, params, t):
    Tw_sim = odeint(air2water_ode, Tw0, t, args=(Ta, params))
    return Tw_sim.flatten()

# Objective function for optimization
def objective_function(params, Ta, Tw_obs, t):
    Tw_sim = solve_ode(Ta, Tw_obs[0], params, t)
    rmse = np.sqrt(np.mean((Tw_sim - Tw_obs) ** 2))
    return rmse

# Calibration of model parameters
def calibrate_model(Ta_obs, Tw_obs):
    t = np.arange(len(Ta_obs))
    initial_params = [0.1, 0.0]  # Initial guesses for K and Teq_offset
    result = minimize(objective_function, initial_params, args=(Ta_obs, Tw_obs, t), method='L-BFGS-B')
    return result.x

# Main function to run the model
def run_model(Ta_obs, Tw_obs):
    # Calibrate model parameters
    calibrated_params = calibrate_model(Ta_obs, Tw_obs)
    
    # Solve the ODE with calibrated parameters
    t = np.arange(len(Ta_obs))
    Tw_sim = solve_ode(Ta_obs, Tw_obs[0], calibrated_params, t)
    
    # Calculate goodness-of-fit metric
    rmse = np.sqrt(np.mean((Tw_sim - Tw_obs) ** 2))
    print(f"Calibrated Parameters: {calibrated_params}")
    print(f"RMSE: {rmse}")
    
    # Visualization
    plt.figure(figsize=(10, 5))
    plt.plot(t, Tw_obs, label='Observed Water Temperature', color='blue')
    plt.plot(t, Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
    plt.xlabel('Time (days)')
    plt.ylabel('Water Temperature (°C)')
    plt.title('Simulated vs Observed Water Temperature')
    plt.legend()
    plt.show()

```

### Explanation:

1. **ODE Definition**: The ODE models the rate of change of water temperature (`dTw/dt`) as a function of the difference between an equilibrium temperature (`Teq`) and the current water temperature (`Tw`). The equilibrium temperature is modeled as a simple linear function of air temperature (`Ta`) with an offset (`Teq_offset`).

2. **Parameter Calibration**: We use the `scipy.optimize.minimize` function with the L-BFGS-B method to find the optimal parameters (`K` and `Teq_offset`) that minimize the RMSE between the simulated and observed water temperatures.

3. **Goodness-of-Fit**: RMSE is used as the goodness-of-fit metric to quantify the model's accuracy.

4. **Visualization**: A plot is generated to visually compare the simulated and observed water temperatures over time.

This implementation provides a basic framework for modeling lake surface temperature using air temperature data, with the flexibility to adjust the model complexity and calibration method as needed.
