To implement the Air2Water-style lake surface temperature model, we'll follow a structured workflow similar to the examples provided. We'll define a simple ODE to model the relationship between air temperature and water temperature, implement the model parameters, solve the ODE numerically, calibrate the parameters using an optimization method, and evaluate the model's performance using a goodness-of-fit metric. Finally, we'll visualize the results.

### Python Code Implementation

```python
import numpy as np
from scipy.integrate import odeint
from scipy.optimize import minimize
import matplotlib.pyplot as plt
from sklearn.metrics import mean_squared_error

# Define the governing ODE
def air2water_ode(Tw, t, Ta, alpha, beta):
    dTw_dt = alpha * (Ta[int(t)] - Tw) + beta
    return dTw_dt

# Numerical solution of the ODE
def solve_ode(Ta, Tw_initial, alpha, beta):
    t = np.arange(len(Ta))
    Tw_sim = odeint(air2water_ode, Tw_initial, t, args=(Ta, alpha, beta))
    return Tw_sim.flatten()

# Objective function for parameter calibration
def objective_function(params, Ta, Tw_obs):
    alpha, beta = params
    Tw_initial = Tw_obs[0]  # Initial condition
    Tw_sim = solve_ode(Ta, Tw_initial, alpha, beta)
    return mean_squared_error(Tw_obs, Tw_sim)

# Calibration of model parameters
def calibrate_parameters(Ta, Tw_obs):
    initial_guess = [0.1, 0.1]  # Initial guess for alpha and beta
    result = minimize(objective_function, initial_guess, args=(Ta, Tw_obs), method='L-BFGS-B', bounds=[(0, 1), (0, 1)])
    return result.x

# Main function to run the model
def run_model(Ta_obs, Tw_obs):
    # Calibrate parameters
    alpha, beta = calibrate_parameters(Ta_obs, Tw_obs)
    print(f"Calibrated parameters: alpha = {alpha}, beta = {beta}")

    # Solve ODE with calibrated parameters
    Tw_initial = Tw_obs[0]
    Tw_sim = solve_ode(Ta_obs, Tw_initial, alpha, beta)

    # Calculate goodness-of-fit metric
    rmse = np.sqrt(mean_squared_error(Tw_obs, Tw_sim))
    print(f"RMSE: {rmse}")

    # Visualization
    plt.figure(figsize=(10, 6))
    plt.plot(Tw_obs, label='Observed Water Temperature', color='blue')
    plt.plot(Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
    plt.xlabel('Time (days)')
    plt.ylabel('Water Temperature (°C)')
    plt.title('Simulated vs Observed Water Temperature')
    plt.legend()
    plt.show()

# Example usage with Ta_obs and Tw_obs
# Ta_obs = np.array([...])  # Air temperature data
# Tw_obs = np.array([...])  # Water temperature data
# run_model(Ta_obs, Tw_obs)
```

### Explanation of the Implementation

1. **ODE Definition**: The ODE `dTw/dt = alpha * (Ta[int(t)] - Tw) + beta` models the change in water temperature (`Tw`) based on the difference between air temperature (`Ta`) and water temperature, with parameters `alpha` and `beta` controlling the rate of change and a constant offset, respectively.

2. **Numerical Solution**: We use `odeint` from SciPy to numerically solve the ODE over the time series.

3. **Parameter Calibration**: We use the `minimize` function from SciPy with the L-BFGS-B method to calibrate the parameters `alpha` and `beta`. The objective function is the mean squared error between observed and simulated water temperatures.

4. **Goodness-of-Fit Metric**: We calculate the Root Mean Square Error (RMSE) to evaluate the model's performance.

5. **Visualization**: We plot the observed and simulated water temperatures to visually assess the model's fit.

This implementation provides a complete workflow for modeling lake surface temperature using air temperature data, with parameter calibration and model evaluation.
