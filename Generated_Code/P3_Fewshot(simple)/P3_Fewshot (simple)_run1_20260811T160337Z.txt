To implement the Air2Water-style lake surface temperature model, we'll follow a structured workflow similar to the examples provided. We'll define a simple ODE to model the change in water temperature based on air temperature, solve it numerically, calibrate the model parameters, and evaluate the model's performance. Here's the complete Python implementation:

```python
import numpy as np
from scipy.integrate import odeint
from scipy.optimize import minimize
import matplotlib.pyplot as plt
from sklearn.metrics import mean_squared_error

# Define the governing ODE
def air2water_ode(Tw, t, Ta, alpha, beta):
    # Tw: current water temperature
    # t: time (not used explicitly as the model is autonomous)
    # Ta: air temperature at time t
    # alpha, beta: model parameters
    dTw_dt = alpha * (Ta - Tw) + beta
    return dTw_dt

# Numerical solution of the ODE
def solve_ode(Ta, Tw_initial, alpha, beta):
    N = len(Ta)
    t = np.arange(N)  # time points
    Tw_sim = odeint(air2water_ode, Tw_initial, t, args=(Ta, alpha, beta))
    return Tw_sim.flatten()

# Objective function for parameter calibration
def objective(params, Ta, Tw_obs):
    alpha, beta = params
    Tw_initial = Tw_obs[0]  # initial condition
    Tw_sim = solve_ode(Ta, Tw_initial, alpha, beta)
    return mean_squared_error(Tw_obs, Tw_sim)

# Calibration of model parameters
def calibrate_model(Ta, Tw_obs):
    initial_guess = [0.1, 0.1]  # initial guess for alpha and beta
    result = minimize(objective, initial_guess, args=(Ta, Tw_obs), method='L-BFGS-B')
    alpha_opt, beta_opt = result.x
    return alpha_opt, beta_opt

# Main function to run the model
def run_model(Ta_obs, Tw_obs):
    # Calibrate model parameters
    alpha_opt, beta_opt = calibrate_model(Ta_obs, Tw_obs)
    
    # Solve the ODE with optimized parameters
    Tw_initial = Tw_obs[0]
    Tw_sim = solve_ode(Ta_obs, Tw_initial, alpha_opt, beta_opt)
    
    # Calculate goodness-of-fit metric (RMSE)
    rmse = np.sqrt(mean_squared_error(Tw_obs, Tw_sim))
    print(f"Optimized Parameters: alpha = {alpha_opt}, beta = {beta_opt}")
    print(f"RMSE: {rmse}")
    
    # Visualization
    plt.figure(figsize=(10, 6))
    plt.plot(Tw_obs, label='Observed Water Temperature', color='blue')
    plt.plot(Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
    plt.xlabel('Time (days)')
    plt.ylabel('Water Temperature (°C)')
    plt.title('Observed vs Simulated Water Temperature')
    plt.legend()
    plt.show()

# Example usage with Ta_obs and Tw_obs
# Assuming Ta_obs and Tw_obs are already loaded as 1D NumPy arrays
run_model(Ta_obs, Tw_obs)
```

### Explanation of the Implementation

1. **ODE Definition**: The ODE `dTw/dt = alpha * (Ta - Tw) + beta` models the change in water temperature based on the difference between air and water temperatures, with `alpha` and `beta` as parameters to be calibrated.

2. **Numerical Solution**: We use `odeint` from SciPy to solve the ODE numerically. The function `solve_ode` computes the simulated water temperature over time.

3. **Parameter Calibration**: We use the `minimize` function from SciPy with the L-BFGS-B method to optimize the parameters `alpha` and `beta` by minimizing the mean squared error between observed and simulated water temperatures.

4. **Goodness-of-Fit Metric**: The RMSE is calculated to evaluate the model's performance.

5. **Visualization**: A plot is generated to compare the observed and simulated water temperatures, providing a visual assessment of the model's accuracy.

This implementation provides a complete workflow for modeling lake surface temperature using air temperature data, with parameter calibration and model evaluation included.
