Below is a complete Python implementation of an Air2Water-style lake surface temperature model. This implementation includes defining the governing ordinary differential equation (ODE), implementing model parameters, numerically solving the ODE, calibrating the model parameters, and visualizing the results.

```python
import numpy as np
from scipy.integrate import odeint
from scipy.optimize import minimize
import matplotlib.pyplot as plt
from sklearn.metrics import mean_squared_error

# Define the governing ODE for the Air2Water model
def air2water_ode(Tw, t, Ta, alpha, beta, gamma):
    dTw_dt = alpha * (Ta[int(t)] - Tw) + beta * (Ta[int(t)] - Tw)**2 + gamma
    return dTw_dt

# Function to simulate water temperature using the ODE
def simulate_water_temperature(Ta, Tw_initial, alpha, beta, gamma):
    N = len(Ta)
    t = np.arange(N)
    Tw_sim = odeint(air2water_ode, Tw_initial, t, args=(Ta, alpha, beta, gamma))
    return Tw_sim.flatten()

# Objective function for optimization
def objective_function(params, Ta, Tw_obs):
    alpha, beta, gamma = params
    Tw_initial = Tw_obs[0]
    Tw_sim = simulate_water_temperature(Ta, Tw_initial, alpha, beta, gamma)
    mse = mean_squared_error(Tw_obs, Tw_sim)
    return mse

def calculate_nse(Tw_obs, Tw_sim):
    nse = 1 - np.sum((Tw_obs - Tw_sim) ** 2) / np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)
    return nse

# Calibrate model parameters using optimization
def calibrate_model(Ta, Tw_obs):
    initial_guess = [0.1, 0.01, 0.0]
    bounds = [(0, 1), (0, 1), (-5, 5)]
    result = minimize(objective_function, initial_guess, args=(Ta, Tw_obs), bounds=bounds, method='L-BFGS-B')
    return result.x

# Main function to run the model
def run_model(Ta_obs, Tw_obs):
    # Calibrate model parameters
    alpha, beta, gamma = calibrate_model(Ta_obs, Tw_obs)
    
    # Simulate water temperature with calibrated parameters
    Tw_initial = Tw_obs[0]
    Tw_sim = simulate_water_temperature(Ta_obs, Tw_initial, alpha, beta, gamma)
    
    # Calculate goodness-of-fit metric (R-squared)
    mse = mean_squared_error(Tw_obs, Tw_sim)
    r_squared = 1 - (mse / np.var(Tw_obs))
    
    # Plot observed vs simulated water temperature
    plt.figure(figsize=(10, 5))
    plt.plot(Tw_obs, label='Observed Water Temperature', color='blue')
    plt.plot(Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
    plt.xlabel('Time (days)')
    plt.ylabel('Water Temperature (°C)')
    plt.title('Observed vs Simulated Water Temperature')
    plt.legend()
    plt.show()
    
    return alpha, beta, gamma, r_squared
```

### Explanation of the Implementation

1. **Governing ODE**: The model is based on a simple ODE that describes the rate of change of water temperature (`dTw_dt`) as a function of air temperature (`Ta`) and current water temperature (`Tw`). The parameters `alpha`, `beta`, and `gamma` control the influence of air temperature on water temperature.

2. **Model Parameters**: The parameters `alpha`, `beta`, and `gamma` are initially guessed and then calibrated using optimization.

3. **Numerical Solution**: The `odeint` function from `scipy.integrate` is used to numerically solve the ODE over the time series.

4. **Calibration**: The model parameters are calibrated using the `minimize` function from `scipy.optimize`, which minimizes the mean squared error between observed and simulated water temperatures. The L-BFGS-B method is chosen for its efficiency in handling bounded optimization problems.

5. **Goodness-of-Fit**: The R-squared metric is used to evaluate the goodness-of-fit of the model, indicating how well the simulated data matches the observed data.

6. **Visualization**: A plot is generated to visually compare the observed and simulated water temperatures, providing an intuitive understanding of the model's performance.
