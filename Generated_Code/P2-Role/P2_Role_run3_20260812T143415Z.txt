Below is a complete Python implementation of an Air2Water-style lake surface temperature model. This implementation includes defining the governing ordinary differential equation (ODE), implementing model parameters, numerically solving the ODE, calibrating the model parameters, and visualizing the results.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint
from scipy.optimize import minimize
from sklearn.metrics import mean_squared_error

# Define the governing ODE for the Air2Water model
def air2water_ode(Tw, t, Ta, alpha, beta, gamma):
    dTw_dt = alpha * (Ta[int(t)] - Tw) + beta * (Ta[int(t)] - Tw)**2 + gamma
    return dTw_dt

# Function to solve the ODE
def solve_ode(Ta, Tw_initial, alpha, beta, gamma):
    t = np.arange(len(Ta))
    Tw_sim = odeint(air2water_ode, Tw_initial, t, args=(Ta, alpha, beta, gamma))
    return Tw_sim.flatten()

# Objective function for optimization
def objective_function(params, Ta, Tw_obs):
    alpha, beta, gamma = params
    Tw_initial = Tw_obs[0]
    Tw_sim = solve_ode(Ta, Tw_initial, alpha, beta, gamma)
    mse = mean_squared_error(Tw_obs, Tw_sim)
    return mse

def calculate_nse(Tw_obs, Tw_sim):
    nse = 1 - np.sum((Tw_obs - Tw_sim) ** 2) / np.sum((Tw_obs - np.mean(Tw_obs)) ** 2)
    return nse

# Calibrate the model parameters
def calibrate_model(Ta, Tw_obs):
    initial_guess = [0.1, 0.01, 0.0]
    bounds = [(0, 1), (0, 1), (-1, 1)]
    result = minimize(objective_function, initial_guess, args=(Ta, Tw_obs), bounds=bounds, method='L-BFGS-B')
    return result.x

# Main function to run the model
def run_model(Ta_obs, Tw_obs):
    # Calibrate the model
    alpha, beta, gamma = calibrate_model(Ta_obs, Tw_obs)
    
    # Solve the ODE with calibrated parameters
    Tw_initial = Tw_obs[0]
    Tw_sim = solve_ode(Ta_obs, Tw_initial, alpha, beta, gamma)
    
    # Calculate goodness-of-fit metric (R-squared)
    mse = mean_squared_error(Tw_obs, Tw_sim)
    r_squared = 1 - (mse / np.var(Tw_obs))
    
    # Plot the results
    plt.figure(figsize=(10, 6))
    plt.plot(Tw_obs, label='Observed Water Temperature', color='blue')
    plt.plot(Tw_sim, label='Simulated Water Temperature', color='red', linestyle='--')
    plt.xlabel('Time (days)')
    plt.ylabel('Water Temperature (°C)')
    plt.title('Simulated vs Observed Water Temperature')
    plt.legend()
    plt.show()
    
    return alpha, beta, gamma, r_squared

# Example usage
# Assuming Ta_obs and Tw_obs are already loaded as numpy arrays
alpha, beta, gamma, r_squared = run_model(Ta_obs, Tw_obs)
print(f"Calibrated Parameters: alpha={alpha}, beta={beta}, gamma={gamma}")
print(f"Goodness-of-fit (R-squared): {r_squared:.4f}")
```

### Explanation of the Implementation

1. **Governing ODE**: The model is based on a simple ODE that describes the rate of change of water temperature (`Tw`) as a function of air temperature (`Ta`). The parameters `alpha`, `beta`, and `gamma` are used to model the linear and nonlinear effects of air temperature on water temperature.

2. **Numerical Solution**: The `odeint` function from `scipy.integrate` is used to numerically solve the ODE over the time series.

3. **Calibration**: The model parameters (`alpha`, `beta`, `gamma`) are calibrated using the `minimize` function from `scipy.optimize`, which minimizes the mean squared error between observed and simulated water temperatures. The L-BFGS-B method is chosen for its efficiency and ability to handle bounds.

4. **Goodness-of-Fit**: The R-squared metric is used to evaluate the goodness-of-fit of the model, providing a measure of how well the simulated data matches the observed data.

5. **Visualization**: A plot is generated to visually compare the observed and simulated water temperatures, allowing for a qualitative assessment of the model's performance.

This implementation provides a comprehensive approach to modeling lake surface temperature using air temperature data, with a focus on parameter calibration and model validation.
